## STRZAL W 10-TKĘ

A modern, responsive, and high-performance website designed for Strzał w 10-tkę restaurant. This project focuses on providing a great user experience, from getting to know more about the restaurant to placing an order.

## TECH STACK

1. React
2. Tailwind CSS
